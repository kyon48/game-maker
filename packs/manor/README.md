# 빗소리 저택: 봉인된 약속

폭우에 갇힌 저택에서 사라진 유언장을 찾는 한국어 미스터리. 예상 플레이 시간은 대사를 읽으며 조사할 때 5~10분이다.

`npm run dev` 후 `http://localhost:5173/?pack=manor`에서 시작한다. 방향키/WASD로 이동, Enter/Z/Space로 대화·조사·글 진행, 위/아래와 확인 키로 선택한다. 글이 나오고 있을 때 확인하면 전체가 표시되고, 다시 확인하면 다음으로 넘어간다.

현관홀 왼쪽 금색 문은 서재, 오른쪽은 도서실, 위쪽은 온실이다. 황금색 물건은 미조사 기록, 조사한 물건은 푸른색으로 바뀐다. 홀 오른쪽 아래 파란 기록대에서 저장하거나 단서 수첩을 읽는다. 아래쪽 정문에서 최종 선택을 한다. 결론 전에 저장해 두면 새로고침 후 다른 선택을 살펴볼 수 있다.

- 현관홀: 집사 도윤, 멈춘 시계, 안내판, 기록대, 정문.
- 서재: 봉인의 발송 기록, 편지철.
- 도서실: 기록관 해린, 대출 장부.
- 온실: 정원사 무진, 치료제 영수증, 배회하는 관리인.

결말은 세 종류다. 기록을 충분히 모아 공개하거나, 해린을 신뢰하고 약속을 조용히 넘기거나, 의심만으로 지목할 수 있다. 단서 수와 핵심 기록·신뢰에 따라 선택지가 달라진다. 모든 단서는 재조사할 수 있지만 수집 수가 중복 증가하지 않는다.

검증: `npm run validate -- manor`, `npm run scenarios -- manor`. 배포: `npm run build -- manor`, `npx vite preview --outDir dist/manor`. 에셋 출처와 생성 명령은 CREDITS.md에 있다.
