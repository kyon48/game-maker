# 밤길의 약속

대표에게 대화하면 논쟁이 시작됩니다. 두 라운드에서 반박 → 함께 지킬 이유 → 대표를 선택하면 승리, 침묵을 반복하면 패배합니다. 효과음과 대사는 일반 플레이·촬영 모두에 적용됩니다.

검증: npm run scenarios -- debate (승리·패배·도주), npm run films -- debate. 녹화: npm run film -- debate win. 실제 영상은 459프레임·15.3초·1080p·30fps이며 화면을 확인했다. film:verify는 이 전투를 두 번 녹화해 459개 RGBA 해시 일치를 검사한다. 출력 out/은 커밋하지 않는다.
