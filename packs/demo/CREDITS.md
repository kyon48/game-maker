# 에셋 출처

- `assets/tilesets/colors.png`: 이 프로젝트에서 `tools/generate-tiles.ts`로 생성한 단색 타일셋. 외부 에셋 없음. CC0-1.0으로 제공.
- `maps/village.tmj`: 이 프로젝트에서 직접 작성한 30×20 Tiled JSON 맵. CC0-1.0으로 제공.
- `assets/characters/hero.png`: 이 프로젝트에서 `tools/generate-character.ts`로 생성한 3열×4방향 캐릭터 시트. 외부 에셋 없음. CC0-1.0으로 제공.
- `assets/fonts/Galmuri11.woff2`: Galmuri11, 저작자 Lee Minseo (quiple), Copyright 2019–2025. SIL Open Font License 1.1 (OFL-1.1). 출처: https://github.com/quiple/galmuri 및 https://www.npmjs.com/package/galmuri (2.40.3). `npm run fonts`로 원본 파일을 복사. 라이선스 전문: `assets/fonts/OFL.txt`.

- `maps/house.tmj`: 이 프로젝트에서 직접 작성한 12×10 Tiled JSON 실내 맵. CC0-1.0.
- `assets/tilesets/house.png`: 자체 생성 단색 타일셋. CC0-1.0. 재생성: `npm run tiles -- packs/demo/assets/tilesets/house.png house`.
- `assets/characters/keeper.png`: 자체 생성 집주인 캐릭터 시트. CC0-1.0. 재생성: `npm run characters -- packs/demo/assets/characters/keeper.png keeper`.
