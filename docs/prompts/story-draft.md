# 스토리 초안 단계별 프롬프트

08 §3.1의 다섯 단계를 GPT(또는 다른 LLM)에 시킬 때 쓰는 템플릿이다. 각 단계는 **새 대화**에서 시작하고, 앞 단계에서 사람이 확인·수정한 JSON을 `{…}` 자리에 붙여 넣는다. 결과는 `packs/<id>/story/draft/` 같은 곳에 단계별 파일로 남겨 두면 나중에 장면 하나만 다시 만들 때 편하다.

공통 규칙(모든 단계 맨 앞에 붙인다):

```
너는 RPG 쯔꾸르풍 게임으로 만들어 유튜브 영상으로 녹화할 이야기를 설계하는 작가다.
- 출력은 요청한 JSON 하나만. 설명·코드블록 바깥 문장을 쓰지 않는다.
- id는 영문 소문자·숫자·밑줄만 쓴다.
- 앞 단계 자료에 없는 인물·장소·설정을 새로 만들지 않는다. 필요하면 JSON의 "questions" 배열에 질문으로 남긴다.
```

## 1단계: 줄거리

```
[기획 메모]
{장르, 분위기, 원작이 있으면 다룰 범위, 영상 길이 목표(첫 영상 8~10분)}

위 기획으로 줄거리를 짜라. 장은 3~5개, 결말은 2개 이하.
각 장은 영상에서 1~3분 분량이다.

출력 형식:
{
  "title": "작품 제목",
  "synopsis": "5문장 이내",
  "chapters": [
    { "title": "1장. …", "summary": "3문장 이내", "turningPoint": "이 장에서 바뀌는 것" }
  ],
  "endings": [ { "id": "ending_…", "condition": "어떤 선택/상태에서", "summary": "1~2문장" } ],
  "questions": []
}
```

## 2단계: 인물표

```
[줄거리]
{1단계 JSON}

등장인물을 최대 5명으로 정리하라. 주인공(플레이어)을 첫 번째로.
말투는 서로 확실히 구별되게: 종결어미, 자주 쓰는 표현, 문장 길이를 구체적으로.

출력 형식:
{
  "characters": [
    { "id": "sora", "name": "표시 이름", "role": "주인공|조력자|대립…",
      "personality": "2문장", "speech": "말투 규칙 2~3개", "sampleLines": ["대사 예시 2개"],
      "art": "base", "voice": "" }
  ],
  "questions": []
}
```

`art`(에셋 캐릭터 폴더)와 `voice`는 사람이 채운다.

## 3단계: 장소표

```
[줄거리]
{1단계 JSON}

장소를 3~6개로 정리하라. 같은 장소를 여러 장면에서 다시 쓰는 편이 좋다.
mood는 다음 중 하나: calm, warm, bright, tense, mystery, sad.

출력 형식:
{
  "locations": [
    { "id": "pier", "name": "선착장", "description": "2문장, 인물 묘사 제외",
      "timeOfDay": "밤", "mood": "mystery", "landmarks": ["게임 맵에 둘 사물 3~5개"],
      "connects": ["tower"] }
  ],
  "questions": []
}
```

`connects`는 문으로 이어지는 장소다. 이걸 보고 사람이 ASCII 레이아웃을 그린다(08 §2.2).

## 4단계: 장면 목록

```
[줄거리] {1단계 JSON}
[인물표] {2단계 JSON}
[장소표] {3단계 JSON}

장마다 장면 1~3개로 나눠라. 장면은 한 장소에서 일어난다.
선택지는 플래그를 남기는 것만 만든다. 촬영에서 고를 선택지를 "filmChoice"로 표시한다.

출력 형식:
{
  "flags": ["met_elder"],
  "vars": [ { "name": "trust", "initial": 0 } ],
  "scenes": [
    { "chapter": "1장. …", "title": "장면 제목", "location": "pier",
      "characters": ["sora", "elder"], "goal": "이 장면에서 일어나는 일 2문장",
      "trigger": "자동 시작|인물에게 말 걸기|장소 진입",
      "choices": [ { "prompt": "…", "options": [ { "label": "…", "sets": ["met_elder"], "filmChoice": true } ] } ],
      "requires": ["이 장면이 열리는 조건 플래그"], "mood": "mystery" }
  ],
  "questions": []
}
```

## 5단계: 장면별 대본 (story.md 조각)

장면 하나씩 요청한다. 첫 요청에만 문법을 길게 넣고, 이어지는 요청에는 직전 장면 마지막 5줄을 넣는다.

```
[인물표] {2단계 JSON}
[이 장면] {4단계의 장면 하나}
[직전 장면 마지막 5줄] {없으면 "없음"}

아래 문법으로 이 장면의 story.md 조각만 써라.
- 장면 머리: `### 장면 제목 @ 장소id`
- 나레이션: `> 문장` (한 문장 60자 안팎, 최대 90자. 장면당 1~3줄)
- 대사: `표시이름(표정): 대사`. 표정은 neutral, smile, laugh, surprised, sad, angry, flustered, thinking 중 하나만.
- 지문: `: 문장`
- 이벤트: `@event id at 앵커이름 trigger=action character=인물id` … 들여쓰기 2칸 … `@end`
  - 자동 시작이면 `trigger=auto once`
- 선택지: `? 질문` 아래 `* 옵션`, 촬영에서 고를 것은 `*> 옵션`, 그 아래 들여쓴 줄이 결과
- 상태: `@set 플래그` `@add 변수 1`, 분기: `@if 조건` … `@else` … `@end`
- 이미 끝난 뒤 다시 말을 걸면: `@page when=플래그` 다음에 짧은 대사
- 대사는 인물표의 말투 규칙을 지킨다. 한 대사 40자 이내, 장면당 대사 8~20줄.
- 앵커 이름은 장소표의 landmarks를 영문 id로 바꿔 쓴다(레이아웃의 `@anchor` 선언은 사람이 맞춘다. 없는 앵커는 lint S005로 드러난다).
```

결과를 story.md에 붙인 뒤 `npm run story -- lint <packId>`를 돌리고, 오류 줄을 그대로 다시 넣는다:

```
아래 lint 오류를 고친 장면 조각 전체를 다시 출력하라. 내용은 바꾸지 말고 오류만 고친다.
{lint 출력}
```

## 다듬기: 표정 세분

lint를 통과한 story.md의 핵심 8종 표정을 64종으로 세분할 때:

```
아래 story.md에서 대사 줄의 (표정)만 바꿔라. 다른 글자는 한 글자도 바꾸지 않는다.
쓸 수 있는 표정(한글 이름): {expressions.json의 ko 64개}
같은 인물이 같은 표정을 세 줄 넘게 연속으로 쓰지 않게 한다.

{story.md}
```
